# Changelog

What each release changes for the people using Promus. Settings shows the sections newer than the server's version, so a section is written for them: [releasing](docs/development.md#releasing) has the rules.

## 0.7.1

- In Household, a tap on someone opens Remove from household, and the row shows it can be tapped

- I Hushåll öppnar ett tryck på någon Ta bort från hushållet, och raden visar att den går att trycka på

### Svenska

- Inställningar säger när en ny version av Promus har kommit, vad som ändrats och hur du uppdaterar
